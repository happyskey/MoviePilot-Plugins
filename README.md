# MoviePilot 插件：零速撞种换种

面向 **MoviePilot V2** 的最小可安装第三方插件仓库示例。

## 目录结构

```text
.
├── package.v2.json
├── README.md
├── icons/
└── plugins.v2/
    └── zerospeedreplace/
        ├── __init__.py
        └── README.md
```

## 快速使用

1. 把整个目录推到 GitHub 仓库（默认分支 `main`）
2. 在 MoviePilot 插件市场添加该仓库地址
3. 安装「零速撞种换种」，按插件内说明配置

详细说明见：`plugins.v2/zerospeedreplace/README.md`

## 声明

仅供学习与自用。删种/换种有风险，请先关闭「删除文件」「自动换种」观察日志。
